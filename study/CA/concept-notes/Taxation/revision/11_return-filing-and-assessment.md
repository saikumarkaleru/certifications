# Chapter 11 — Return Filing & Assessment (Revision)

> Verify all dates, 234F fee amounts, interest rates, updated-return window & additional-tax slabs, notice/assessment time limits, 140A appropriation order, 7th-proviso & PAN-inoperative consequences against current ICAI material for your AY. Chapter XIV of the Income-tax Act, 1961 (Secs 139–158).

## Snapshot

- India runs a **self-assessment** system: taxpayer declares & pre-pays; department verifies on a **graded, clocked ladder**.
- Two halves of one bargain: **return** (Sec 139) = taxpayer's declaration; **assessment** = department's response.
- Timing lens unifies everything: declare → **pre-pay as you earn** → verify → **charge interest for every day of slippage** (234A/B/C + 140A).
- Escalating carrots for cooperation, escalating sticks for non-cooperation. Deadlines bind the **department** too (certainty is a taxpayer right).

## Core concepts

- **Return = legal self-assessment, not a request.** Tax already computed & (ideally) paid under **Sec 140A**.
- **Assessment is a spectrum** ordered by escalating friction (see table below).
- Fifth "re-opening" lane: **income escaping assessment — Sec 147, via notice u/s 148** (idea-level for CA Inter; verify limits).
- Design spine: file on time → no cost; file late → fee + interest; don't file / ignore notices → best-judgment estimate + penalty + possible prosecution.

| Assessment type | Section | Who works | Trigger |
|---|---|---|---|
| Self-assessment | 140A | Taxpayer | Every return |
| Summary / processing | 143(1) | CPC computer | Every processed return |
| Scrutiny | 143(3) | Assessing Officer | Selected returns |
| Best judgment | 144 | AO (estimates) | Non-cooperation / non-filing |

99%+ of returns never meet a human — cheap 143(1) handles the mass; expensive 143(3) is a tiny sliver; 144 is the punishment lane.

## Key provisions / rules

### Who must file — Sec 139(1)

- File if **total income BEFORE Chapter VI-A (80C–80U) AND before specified capital-gains exemptions (Secs 54/54B/54D/54EC/54F etc.)** exceeds basic exemption limit. Test on the **pre-deduction / pre-exemption** figure.
- **Companies & firms/LLP: file ALWAYS** — even nil income, loss, or dormant.
- Individual / HUF / AOP / BOI / artificial juridical person: file if pre-deduction income > exemption OR any 7th-proviso trigger met.
- Charitable trusts, political parties, research associations, universities etc.: file if income **before** claiming their exemption > limit.
- **Resident (ROR) with foreign assets:** file **irrespective of income** — holds any asset outside India, signing authority in any foreign account, or beneficiary of any foreign asset.

**7th proviso to Sec 139(1)** — mandatory filing even below limit if (broadly): deposits above specified amount in current accounts; foreign-travel spend above specified amount; electricity bills above specified amount; or other CBDT-notified high-value criteria (turnover, professional receipts, aggregate TDS/TCS). Memory hook: *"Live large → must file."*

### Due dates — Sec 139(1)

| Class of assessee | Due date (verify) |
|---|---|
| Assessee requiring audit under the Act | 31 October of AY |
| Working partner of a firm liable to audit | 31 October of AY |
| Assessee furnishing transfer-pricing report (Sec 92E) | 30 November of AY |
| Any other assessee (salaried, non-audit) | 31 July of AY |

- Dates track **document-readiness** (audit needs months; TP needs cross-border docs).
- **Working partner of audited firm → 31 Oct, NOT 31 July** (due date follows the dependency).
- **Tax-audit report (Form 3CA/3CB + 3CD) due ~1 month BEFORE return due date.** Sequence: audit report → return.

### Three "second chances"

| Feature | Belated 139(4) | Revised 139(5) | Updated 139(8A) |
|---|---|---|---|
| Purpose | Missed due date | Fix bona fide error | Voluntarily disclose extra income later |
| Pre-condition | Didn't file on time | Already filed (orig/belated) | Filed or not |
| Direction of tax | Any | Any (up/down) | **Only up** — never refund/loss |
| Window (verify) | Up to ~3 months before AY-end or before assessment completion, whichever earlier | Same as belated | Multi-year from AY-end |
| Extra cost | 234F fee + 234A interest | None (relates back) | Normal tax + interest + **rising additional tax** |
| Loss c/f | Most losses **lost** | Follows original's status | Cannot create/increase loss |

- **Belated 139(4):** carries 234F + 234A. Hidden penalty = **forfeiture of most loss carry-forwards** (business, speculation, capital, racehorse losses). **Survivors:** house-property loss (Sec 71B) & unabsorbed depreciation (Sec 32(2)) still carry forward.
- **Revised 139(5):** for bona fide omission/wrong statement; **replaces** original (original withdrawn); relates back to original date. Can revise **any number of times**; a **belated return CAN now be revised**. Cannot un-belate a late original; lost losses stay lost.
- **Updated 139(8A):** pay-more-only door. **Cannot** file if it → refund / reduces liability / shows or increases a loss / reduces tax already determined; **barred** where search (Sec 132), requisition (Sec 132A), or survey (Sec 133A) initiated, or assessment/reassessment/revision pending or complete. **Only ONCE per AY.** Additional tax = % of (normal tax + interest), stepping up by band of lateness (earlier = cheaper).

### Defective return — Sec 139(9)

- AO issues intimation; assessee has **15 days (extendable)** to cure.
- Uncured → return treated as **INVALID (never filed)** → lose filing date, exposed to belated costs, may lose loss c/f.
- Return is **NOT invalid the moment a defect exists** — only if uncured within time. AO **may condone** a late cure before assessment.
- Defects include: not filled fully; missing required statements/computations; **self-assessment tax + interest not paid before filing** where required; accounts/audit-report copies not attached.

### PAN — Sec 139A / Aadhaar — Sec 139AA

- **PAN** = lifelong unique 10-character identifier; must be quoted in specified high-value transactions.
- Who must obtain: business/profession with sales/turnover/gross receipts above specified amount; anyone required to file (incl. 7th proviso); resident (non-individual) in a financial transaction of specified aggregate + its directors/partners/trustees/karta/principal officer; importers/exporters; CBDT-notified others.
- **PAN–Aadhaar interchangeable** where linked; Aadhaar-holder without PAN can be allotted PAN on Aadhaar.
- **Sec 139AA:** quote Aadhaar when applying for PAN and when filing. Non-linking → PAN **INOPERATIVE** (not cancelled). While inoperative: **no refund**; **no interest on refund**; **TDS/TCS at higher no-PAN rates**. Person still "has" a PAN. Trap: inoperative ≠ cancelled.

### The four assessments

- **140A — Self-assessment:** compute tax on returned income − TDS/TCS/advance tax + 234A/B/C interest + 234F fee = **balance ("SA tax")** paid **before filing**. Non-payment → **assessee in default**. **Appropriation order (verify): fee → interest → tax**, so shortfall leaves **tax** unpaid.
- **143(1) — Summary/CPC:** arithmetic & consistency checks only (no investigation). Corrects arithmetical errors; disallows internally inconsistent claims; disallows losses/deductions barred in a belated return; disallows audit-report items not taken / includes 26AS/16/16A income not returned; matches tax credit with Form 26AS. Intimation = **deemed notice of demand** (if tax payable) / **deemed refund order** (if refund). **Time limit: 9 months from end of FY in which return filed.** Any adjustment increasing tax / reducing refund/loss needs **prior proposal + 30-day response**.
- **143(3) — Scrutiny:** gated by **Sec 143(2) notice, served within ~3 months from end of FY of filing.** No valid in-time 143(2) → no scrutiny. AO uses **142(1)** inquiries, may order **142(2A) special audit**; passes reasoned order. Largely **faceless (Sec 144B)**. Order must be completed within statutory outer limit from end of AY (verify).
  - **142(1)** = inquiry/subpoena: require non-filer to file, produce accounts/documents, furnish info — with or without a return filed. *142(1) = "give me your papers"; 143(2) = "you're selected for scrutiny."*
  - **142(2A)** = AO-directed special audit by a nominated CA (complex/voluminous/doubtful accounts), with higher-authority approval + opportunity to assessee; **cost borne by department**. Not the assessee's own tax audit.
- **144 — Best judgment:** AO **estimates** income when assessee fails to file (orig/belated/142(1)), or ignores 142(1) / 142(2A) / 143(2). Requires **show-cause opportunity** (dispensable only where a 142(1) produce-notice was already issued & defied); estimate must be **honest & material-based**, not arbitrary. Not a penalty computation.

**Faceless (Sec 144B):** anonymised randomly-allocated units (Assessment, Verification, Technical, Review) under National Faceless Assessment Centre; portal-only, no physical interface; **personal hearing via video-conferencing** on request. Review step = second pair of eyes; removes intimidation/inducement channel.

### Interest & fee — "price of lateness"

| Charge | Section | Punishes | Computation |
|---|---|---|---|
| Late-filing **fee** | 234F | Filing after due date | Flat (smaller if total income below specified level; larger otherwise) — verify amounts |
| Interest | 234A | Gap between due date & filing, on **unpaid** tax | 1% per month/part, due date → filing date |
| Interest | 234B | < 90% of assessed tax paid as advance tax | 1% per month on shortfall, **from 1 April of AY** |
| Interest | 234C | Missed advance-tax instalments | 1% per month for each specified deferment period only |

- **234A = late return; 234B/C = late payment of tax** (can trigger even with on-time return). 234F = flat fee for missing filing date, independent of tax.
- **234A base = tax on total income LESS prepaid taxes** (TDS/TCS/advance tax/relief). If TDS fully covers tax → **234A = nil even if years late** (234F still bites).
- **Part of a month = full month** for 234A/B/C. Never pro-rate days.
- 234B runs 1 April of AY → determination/payment; 234C runs only per-instalment periods then stops (no double-count).
- 234F is **flat, never month-wise**, tiered by total income.
- **Compensatory (A/B/C, time-and-amount driven) vs regulatory (F, flat).**

Advance-tax instalment dates policed by 234C: **15 Jun / 15 Sep / 15 Dec / 15 Mar** (with specified cumulative % — verify).

## Worked mini-example

**Belated filing (Sec 234F + 234A).** Salaried Mr Rao files on **10 Nov** (due 31 July); unpaid tax after TDS = **₹40,000**; 234F = ₹5,000 (income above ₹5 lakh slab); 234A = 1%/month.
- Belated return u/s 139(4).
- 234F fee = **₹5,000** (flat).
- 234A months: Aug, Sep, Oct, part-Nov = **4 months** (part = full). Interest = ₹40,000 × 1% × 4 = **₹1,600**.
- Extra cost of lateness = ₹5,000 + ₹1,600 = **₹6,600**, on top of ₹40,000 tax → deposit ₹46,600 as SA tax u/s 140A before filing.
- **Variation:** if TDS had fully covered tax (unpaid = ₹0) → 234A = **₹0**, but **234F ₹5,000 still applies** (regulation vs compensation).

**140A appropriation trap.** Tax ₹92,000, TDS ₹50,000, files 15 Sep (due 31 July), deposits only ₹40,000.
- Balance tax = ₹42,000; 234A = ₹42,000 × 1% × 2 months = ₹840; 234F = ₹5,000; total due = ₹47,840.
- Appropriate **fee → interest → tax**: ₹5,000 (fee) → ₹840 (interest) → ₹34,160 to tax.
- **Unpaid tax = ₹42,000 − ₹34,160 = ₹7,840** → Mr Sen is an **assessee in default** for ₹7,840 (tax), keeping recovery/234B meter running. Because fee & interest go first, the whole shortfall lands on tax (worst place).

## Exam traps & must-remember

1. **Threshold tested BEFORE Chapter VI-A deductions** (and add back specified capital-gains rollover exemptions). Don't subtract 80C first.
2. **234F is a fee, not interest/tax** — flat, not month-wise, bites even when tax nil.
3. **234A vs 234B/C:** 234A = late return; 234B/C = late advance-tax. Part-month = whole month for all three. 234A only on **unpaid** tax.
4. **Revised return needs a filed return** — cannot un-belate a late original or restore lost losses.
5. **Updated 139(8A) = pay-more-only, once per AY;** barred on search/survey/pending or complete assessment; never refund/loss/reduction. Most-tested cluster.
6. **Uncured defective return → invalid (never filed);** but not invalid until cure period lapses; AO may condone.
7. **No 143(3) without valid in-time 143(2) notice.** Don't confuse 143(2) gateway with 142(1) inquiry.
8. **143(1) mechanical only, but not lawless** — needs prior proposal + 30-day response before increasing tax/reducing refund. CPC "examining evidence" or silent demand = wrong lane.
9. **144 must still be a reasonable, material-based honest estimate** after show-cause (narrow dispensation aside), not a punishment figure.
10. **PAN inoperative ≠ cancelled** — higher TDS, blocked refund, no interest on refund; person still "has" PAN.
11. **Working partner of audited firm → 31 Oct, not 31 July.**
12. **Audit report due ~1 month before return** — sequence matters.
13. **140A appropriation: fee → interest → tax** → shortfall leaves tax unpaid → assessee in default.
14. **143(1) intimation/refund is NOT final** — scrutiny (143(2)/143(3)) & reassessment (147/148) can still follow. "Refund received" ≠ "case closed."

**Connections:** loss c/f (Secs 70–80) needs filing by 139(1) due date (except house-property loss & unabsorbed depreciation); advance tax (Secs 208–219) enforced by 234B/C; 143(1) matches Form 26AS; inoperative PAN → higher TDS; ROR foreign assets enforce global-income; penalties Sec 270A + prosecution sit above civil charges.

## One-line recall

- **Declare (139) + pre-pay (advance tax + 140A); State verifies on a clocked graded ladder; lateness priced by compensation (234A/B/C) + flat fee (234F); honest correction gets second chances graded by lateness & direction of tax; identity fixed by PAN (139A) + Aadhaar (139AA).**
- Due dates: audit & audited-firm partners **31 Oct** · TP report (92E) **30 Nov** · others **31 July** · audit report ~1 month earlier.
- Second-chance doors: belated 139(4) (cost + lose losses) · revised 139(5) (any direction, replaces original) · updated 139(8A) (pay-more only, once) · defective 139(9) (cure in 15 days).
- Assessments: 140A self · 143(1) CPC 9-month summary · 143(3) scrutiny (needs 143(2) in ~3 months) · 144 best judgment · 147/148 reassessment of escaped income.
- Appropriation **fee → interest → tax**; leftover = tax default = assessee in default.
- 234A base = **unpaid** tax only; nil if TDS covers it, but 234F still bites.
