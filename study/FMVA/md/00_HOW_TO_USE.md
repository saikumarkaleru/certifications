# FMVA Study Guide — How to Use

Concept-first notes for CFI's **Financial Modeling & Valuation Analyst (FMVA)** — every concept explained by *why it exists and how to build it*, with step-by-step model logic, formulas, worked examples, diagrams, and practice Q&A. One consolidated PDF.

## The one rule that matters
> **FMVA is a *doing* skill.** This guide teaches every concept, formula, and cell-by-cell build step — but you only get hired because you can *build the model in Excel*. Read a chapter here → then **build it yourself in Excel**. The notes are the companion; the reps are the point.

## How each chapter is structured
1. **The Problem** — what real analyst need this technique solves
2. **The Core Idea** — the principle in plain language
3. **Why it works** — the logic behind the method
4. **Full technical content** — formulas + the cell-by-cell build logic + formatting/best practice
5. **Worked examples** — numbers you can reproduce in Excel
6. **Connections** — how it links to the rest of the model/valuation
7. **Traps & common errors** — what breaks models and loses interviews
8. **First-principles recap**
9. **Quick-reference** — formulas, functions, shortcuts

## How to study
1. Read the chapter (the *why* + the *how-to-build*).
2. **Rebuild it in Excel from scratch** — no templates.
3. Do the chapter's practice Q&A.
4. Every 3–4 chapters, integrate into one growing model.
5. Finish with the **end-to-end model** + **equity-research note** chapters → those become your **portfolio** (the thing that gets interviews).

## Coverage
Foundations (Excel, accounting, corporate finance, ratios) → Financial Modeling (full 3-statement model, scenarios, FP&A) → Valuation (DCF, comps, precedent transactions) → High-value electives (M&A, LBO, credit, capital budgeting) → Analytics & presentation (dashboards, Power BI, pitchbooks) → Putting it together (full model, research note, best practices).
