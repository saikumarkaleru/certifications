# Quant / Derivatives Analyst — Projects

Two core options projects (plus a technical-research sub-folder), kept simple and
fully explainable, each with a plain-English **study guide** for interview prep.

| Project | What it does |
|---------|--------------|
| [`1_black_scholes_pricer`](1_black_scholes_pricer) | Black-Scholes call/put pricing + the five Greeks (delta, gamma, vega, theta, rho), with payoff and sensitivity charts. |
| [`2_options_strategy_payoffs`](2_options_strategy_payoffs) | Common option strategies built from legs — payoff at expiry, max profit/loss, breakevens, payoff diagrams. |
| [`technical_research_analyst/`](technical_research_analyst) | Nifty/Bank Nifty systematic backtester, daily research-note engine, and coverage watchlist. |

Each core project is one readable `main.py` with Excel/chart output, plus
`STUDY_GUIDE.md` (pitch, Greeks explained, options Q&A). Run: `python main.py`.
