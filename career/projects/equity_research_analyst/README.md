# Equity Research Analyst — Projects

Two core valuation projects, kept simple and fully explainable, each with a
plain-English **study guide** for interview prep.

| Project | What it does |
|---------|--------------|
| [`1_dcf_valuation`](1_dcf_valuation) | Discounted-cash-flow model: 5-year FCF, WACC discounting, Gordon terminal value, intrinsic price per share + WACC×growth sensitivity. |
| [`2_comparable_company_analysis`](2_comparable_company_analysis) | Peer trading multiples (P/E, EV/EBITDA, EV/Revenue, P/B) → implied valuation range vs current price. |

Each is one readable `main.py` with Excel/chart output, plus `STUDY_GUIDE.md`
(pitch, how it works, DCF-vs-comps Q&A). Run: `python main.py`.
