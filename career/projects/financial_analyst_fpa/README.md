# Financial Analyst / FP&A — Projects

Two core FP&A projects, kept deliberately simple and fully explainable, each with
a plain-English **study guide** for interview prep.

| Project | What it does |
|---------|--------------|
| [`1_three_statement_model`](1_three_statement_model) | Linked income statement, balance sheet & cash flow with a 5-year forecast off operating drivers; balance sheet ties out every year. |
| [`2_budget_vs_actual`](2_budget_vs_actual) | Monthly budget-vs-actual variance with favorable/unfavorable flags, a price/volume revenue decomposition, and auto-generated commentary. |

Each project is one readable, commented `main.py` producing an Excel workbook, plus
`STUDY_GUIDE.md` (30-second pitch, how it works, interview Q&A). Run: `python main.py`.
