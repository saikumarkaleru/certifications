Original, from-scratch study notes for **CA Intermediate (ICAI, New Scheme)** — built to teach every topic by **why it exists and why it works that way**, so nothing is rote-memorized. Each subject is a single consolidated PDF containing deep concept explanations **plus** a full exam Q&A bank, with diagrams throughout.

## 🧠 How each chapter is structured

Every chapter follows the same concept-first skeleton:

1. **The Problem** — the real situation that created the need
2. **The Core Idea** — the underlying principle, in plain language
3. **Why it's built this way** — the logic behind each rule
4. **Full Technical Content** — all exam-required provisions/formats/computations, taught with the "why"
5. **Worked Examples** — step-by-step, easy → exam-hard
6. **Presentation & Disclosure / formats**
7. **Connections** — links across chapters and subjects
8. **Traps & Examiner Tricks**
9. **First-Principles Recap**
10. **Quick-Revision Sheet**

Each chapter is immediately followed by its **exam Q&A bank** (concept-checks, graded computational/scenario problems, past-paper-style questions, and MCQs — every question with a full model answer).
